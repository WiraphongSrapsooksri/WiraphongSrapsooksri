# Hi, I'm Wiraphong (Max) 👋

**Data Engineer @ Maholan** — I build data pipelines, on-prem data platforms, and applied AI systems for enterprise and public-sector clients.

When something is slow or broken, I break the system into layers and trace it until I find the bottleneck, then benchmark the fix to prove it worked.

---

### 🔧 What I work on

**Data pipelines & integration**
- ETL from heterogeneous sources: **SAP (RFC)**, PostgreSQL, Oracle, MSSQL, DB2, MySQL, MongoDB, Hive/Impala
- Orchestration with **Apache Airflow** on Docker-based, on-prem infrastructure
- Lakehouse work on **Apache Iceberg** (Cloudera)
- Data Sharing API: token-based REST service that serves data from 10 database types to downstream consumers

**Database engineering**
- Schema change management with **Flyway + Jenkins** across dev / staging / prod
- PostgreSQL performance tuning: autovacuum, bloat control, materialized view refresh strategy
- Pipeline monitoring dashboards (FastAPI + Next.js) and observability with **Prometheus + Grafana**

**Applied AI**
- **GraphRAG** with reasoning paths and citations, running on local 7–9B LLMs
- Semantic search over a data catalog (**OpenMetadata**) using **Qdrant** multi-vector retrieval and reranking, including Thai typo correction
- AI Hub: model catalog and registry that pulls metadata from vLLM / Hugging Face / OpenRouter
- RAG pipelines for Thai-language documents

**Data governance & identity**
- Data governance tooling and data catalog products
- SSO with **Keycloak** + AD/LDAP

---

### 🔬 Research & benchmarks
- **Row vs columnar data transfer:** PEP 249 (DB-API) vs Apache Arrow / ADBC for pulling data out of databases
- **Compute engine benchmark:** comparing query engines against pre-materialized datasets
